# Phase 3 验收报告

日期：2026-08-01  
平台：ROS 2 Humble、Gazebo Fortress、UR5、`ros2_control`

## 1. 验收范围

Phase 3 的目标是在 Gazebo 中完成静态目标闭环 IBVS：

1. 从规定初始姿态获取红色目标和绿色末端特征；
2. 根据图像误差生成笛卡尔速度；
3. 通过特征点雅可比和速度级逆运动学生成关节命令；
4. 从初始误差约 149 px 收敛到 5 px 死区内；
5. 收敛过程中不出现明显振荡、跳动、方向错误或特征丢失；
6. 静态目标被绿色特征遮挡后，继续使用锁存坐标完成收敛；
7. 动态模式中目标数据超时后安全保持。

本报告不把真实机器人安全、动态目标完全遮挡预测或三维最短路径纳入 Phase 3 完成标准。

## 2. 问题与修复路径

初始版本能够向正确方向运动，但速度慢、接近目标时欠收敛，且图像路径缺少量化证据。修复过程遵循“现象、假设、单变量实验、证据、修改、再验证”的顺序。

主要修复如下：

1. 分别跟踪目标和特征消息状态，在输入缺失时保持位置；
2. 将控制增益、速度、频率、超时和轨迹持续时间参数化；
3. 用标准 DH 链计算绿色特征点完整 `3x6` 几何雅可比，并用中心差分验证；
4. 修正 DH 基坐标到 ROS `base_link` 的方向映射；
5. 用范数等比例限速代替逐分量裁剪，保持速度方向；
6. 使用阻尼最小二乘抑制近奇异位形的关节速度放大；
7. 加入零空间姿态目标，使初始低秩雅可比逐步恢复；
8. 修正图像误差到基坐标速度的符号与轴对应关系；
9. 将主要视觉任务与次要姿态任务分级限速，避免姿态任务拖慢视觉任务；
10. 对静态目标锁存首次坐标，解决接近成功时红色目标被遮挡而停止的问题；
11. 保留动态目标模式，要求目标持续更新并在超时后安全保持；
12. 固化经过仿真验证的默认参数，并修复重复关闭 ROS 上下文的退出异常。

## 4. 指标定义

### 4.1 图像误差

```text
e = s - s*
||e|| = sqrt(e_u^2 + e_v^2)
```

其中 `s` 是绿色特征质心，`s*` 是红色目标质心。

### 4.2 收敛时间

从第一条有效控制日志到首次进入 `||e|| < 5 px` 的时间。

### 4.3 图像路径效率

```text
eta = 起点到终点直线距离 / 实际累计路径长度
```

质心坐标是整数像素，理想斜线也会形成横竖交替的楼梯路径。因此分析器先使用 1.5 px 容差简化路径，再计算 `eta`。同时报告原始路径长度、RMS 横向偏差和最大横向偏差。

`eta` 越接近 1，二维图像轨迹越接近直线。该指标不证明关节空间或三维末端轨迹最短。

## 5. 重复实验结果

三次实验均从相同初始姿态和约 `[-96, 114] px` 的初始误差开始，使用默认参数且不添加命令行覆盖。

| 指标 | Trial 1 | Trial 2 | Trial 3 |
|---|---:|---:|---:|
| 成功 | 是 | 是 | 是 |
| 初始误差 / px | 149.037 | 149.037 | 149.037 |
| 死区误差 / px | 4.2 | 4.2 | 4.2 |
| 收敛时间 / s | 80.198 | 81.099 | 82.204 |
| 路径效率 | 0.9951 | 0.9951 | 0.9951 |
| RMS 横向偏差 / px | 1.965 | 1.945 | 1.959 |
| 最大横向偏差 / px | 3.575 | 3.575 | 3.575 |
| 最大命令关节速度 / rad/s | 0.600 | 0.600 | 0.600 |
| 最小奇异值 | 0.0001 | 0.0001 | 0.0001 |
| 误差增大步数 | 1 | 0 | 1 |
| 绿色特征超时 | 0 | 0 | 0 |
| 动态目标超时 | 0 | 0 | 0 |

汇总结果：

- 成功率：`3/3`；
- 平均收敛时间：`81.167 s`；
- 收敛时间样本标准差：`1.005 s`；
- 收敛时间范围：`80.198-82.204 s`；
- 三次路径效率均为 `0.9951`；
- 三次均未出现输入超时。

## 6. 模式验证

### 6.1 静态目标

`static_target=true` 时，控制器锁存首次红色目标坐标。绿色特征接近并遮挡红色目标后，控制器仍继续运行，最终在误差 `4.2 px` 时进入死区并保持。

### 6.2 动态目标

`static_target=false` 时，控制器持续更新目标坐标。测试中只发布一次目标，`0.5 s` 后控制器报告 `Moving target stale or missing` 并保持位置，绿色特征持续发布时没有被误判为超时。

此测试验证了动态目标超时安全逻辑，没有验证真实移动目标的轨迹跟踪性能。

## 7. 验收结论

在上述范围内，Phase 3 通过：

- 默认配置可重复完成静态目标闭环收敛；
- 最终误差小于 5 px；
- 图像误差轨迹接近直线；
- 静态目标遮挡不会导致提前停止；
- 动态目标数据丢失会触发安全保持；
- 进程可在 `SIGINT` 后干净退出；
- 数学与日志分析共 10 项单元测试通过。

## 8. 已知限制

1. 平均收敛时间约 81 s，功能稳定但演示速度仍偏慢；
2. 初始姿态的最小奇异值约为 `0.0001`，前期需要零空间姿态恢复；
3. 路径效率只衡量二维图像轨迹；
4. 固定深度和相机内参尚未进行系统偏差实验；
5. 动态目标完全遮挡后没有速度预测或状态估计；
6. 尚未验证不同初始姿态、图像噪声、延迟、丢帧和控制频率；
7. 尚未实现真实机器人所需的关节位置、加速度、碰撞和急停安全链；
8. 当前结论只适用于 Gazebo 仿真，不能直接迁移为真实机械臂安全参数。

## 9. Phase 4 基线

Phase 4 保持本报告的名义参数和初始条件作为对照组，依次只改变一个因素：

1. 质心高斯噪声、异常点和短时丢帧；
2. `fx`、`fy`、估计深度和工具偏移误差；
3. `20/10/5/2 Hz` 控制频率及匹配的轨迹持续时间；
4. 消息延迟与周期抖动；
5. 不同初始姿态和接近奇异位形程度；
6. 单因素完成后再进行组合压力实验。

每个条件使用固定随机种子并重复运行，比较成功率、收敛时间、最终误差、路径效率、横向偏差、速度峰值、最小奇异值和输入超时次数。

```bash

> /tmp/phase3_trial.log 2>&1
```

```bash
python3 src/ibvs_ur5/scripts/analyze_ibvs_log.py \
  /tmp/phase3_trial.log
```

运行测试：

```bash
python3 -m unittest discover \
  -s src/ibvs_ur5/tests \
  -p 'test_*.py'
```
